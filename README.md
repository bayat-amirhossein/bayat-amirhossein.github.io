# Amirhossein Bayat personal webpage

This is a simple static personal webpage. Open `index.html` in a browser to view it.

## Customize

- Replace `your.email@example.com` in `index.html` with your real email.
- Replace the three placeholder paper cards in the `Papers` section.
- Replace the paper carousel images in the `images` folder. Each paper currently has four image files, for example `images/paper-1-1.svg` through `images/paper-1-4.svg`.
- Put your paper PDFs in a `papers` folder, then update the PDF links in `index.html`, for example `href="papers/my-paper.pdf"`.
- Put your resume PDF in this folder, then change the resume button link from `href="#"` to the PDF filename, for example `href="Amirhossein-Bayat-Resume.pdf"`.
- Update the `Education`, `Experience`, and `Skills` text in the `Resume` section.
- Edit the interest chips in the `Interests` section.
